# User Stories

## Farm Registration

As a farmer,

I want to register my farm details,

So that I can receive personalized recommendations.

---

## Weather Intelligence

As a farmer,

I want to see weather forecasts,

So that I can plan irrigation and crop activities.

---

## AI Farm Advisor

As a farmer,

I want to ask farming questions in natural language,

So that I can make informed decisions.

---

## Smart Selling Assistant

As a farmer,

I want to know current and future crop prices,

So that I can sell at the most profitable time.

---

## Yield Prediction

As a farmer,

I want to estimate my harvest yield,

So that I can plan finances and selling strategies.
